# 行为准则

## 我们的承诺

作为成员、贡献者与维护者，我们承诺让参与本项目的每个人都不受骚扰，无论其年龄、体型、可见或不可见的残障、族裔、性征、性别认同与表达、经验水平、教育程度、社会经济状况、国籍、外貌、种族、宗教或性取向。

## 我们的标准

本项目采用 Contributor Covenant 2.1 版作为行为准则，完整文本见：

- https://www.contributor-covenant.org/version/2/1/code_of_conduct/
- 中文版：https://www.contributor-covenant.org/zh-cn/version/2/1/code_of_conduct/

简而言之：保持尊重与建设性，善意理解他人，接受建设性批评，并以社区整体利益为重。骚扰、人身攻击、挑衅以及公开他人隐私都不可接受。

## 适用范围

本准则适用于所有项目空间（issue、pull request、讨论），也适用于个人在公开场合代表本项目的情形。

## 执行

如遇辱骂、骚扰或其他不可接受的行为，请通过 shareur@imyang.me 联系维护者。报告会被审阅并保密处理。维护者可删除评论、拒绝贡献或封禁违反本准则的账号，执行方式遵循 Contributor Covenant 的执行指南。

## 出处

本行为准则改编自 Contributor Covenant 2.1 版，原文见 https://www.contributor-covenant.org/version/2/1/code_of_conduct/。
