# 安全策略

## 范围

本仓库包含 Arch Linux / CachyOS 软件包的打包配方、辅助脚本与文档，不托管被打包的应用本身。上游应用的安全问题请报告给对应项目；待上游修复后我们会更新配方。

本仓库内的以下问题属于受理范围，例如：

- 配方下载并安装被篡改或未经校验的内容；
- 校验和不匹配，或来源未按文档固定；
- 辅助脚本（validate、ci-build、test-local-install、publish）可能执行意外命令、泄露凭据或意外修改宿主；
- 仓库中误包含机密信息或隐私数据。

## 报告漏洞

请通过邮件私下报告可疑漏洞：

- shareur@imyang.me

敏感报告请勿开公开 issue。请说明受影响的包或脚本、提交或版本、复现步骤与预期影响；如可能，附上最小复现。

## 后续处理

- 我们力争在数天内确认收到报告。
- 我们会确认问题、商定修复，并在你同意时致谢。
- 修复在本仓库发布；配方经审核后可重新发布到 AUR，发布为人工操作且需明确批准。

## 支持版本

仅维护当前 `master` 分支。配方跟踪上游版本，请使用最新提交以及各包目录标明的上游版本。

## 仓库卫生

- 绝不可提交机密、令牌、私钥或个人数据。
- 尽可能使用固定校验和验证来源。
- CI 在一次性容器中验证变更包，仅上传报告。
